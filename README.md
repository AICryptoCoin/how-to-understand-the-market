# «Как понимать рынок»

Учебник современной макроэкономики, который заканчивается работающим инструментом
оценки фазы рынка. **Рыночные часы — пункт назначения, а не предмет.**

Репозиторий закрытый. Причина не в секретности замысла: книга разбирает платный
курс, а `research/SOURCES.md` фиксирует ряды, которые нельзя выкладывать
приложением (NAHB HMI — только копирайт, лицензии нет) и которые закрыты
лицензией для показа (Twelve Data, `Internal non-display usage`). До сплошного
прохода по правам публикация невозможна.

## Входная точка

**`PROGRESS.md`** — начинаешь работу, читаешь его первым. Состояние, журнал
решений, что в работе, очередь, карта источников истины, грабли среды.

## Что где лежит

| Путь | Что это |
|---|---|
| `book/` | сама книга: 40 HTML-страниц, открывается `book/index.html` без сервера |
| `book/assets/chapters.js` | **реестр глав — единственный источник нумерации** |
| `book/tools/audit.py`, `book/tools/linkify.py` | приборы приёмки: девять детекторов и сверка отсылок |
| `synthesis/cheatsheet-spec.md` | **спецификация инструмента: единственное место весов и порогов** |
| `synthesis/classifier-v2.md` | конструкция классификатора и пред-регистрация её проверки |
| `synthesis/indicator-catalog.md` | ~185 показателей: публикаторы, календарь, коды |
| `research/` | контур эмпирических проверок: загрузчик, опись рядов, задачи `Z##` |
| `FULL-BOOK-PLAN.md` | структура 71 главы, порядок работ, реестр задач контура |
| `source-digests/` | конспекты исходного курса |

## Проверка перед коммитом

```bash
cd book && python tools/linkify.py --check && python tools/audit.py && python tools/audit.py --selftest
```

Контур:

```bash
cd research && python smoke.py && python smoke.py --selftest
```

## Ключи

**`.env.research` в корне репозитория** — `FRED_API_KEY`, `BEA_API_KEY`,
`CENSUS_API_KEY`. Файл покрыт `.gitignore`, читается из окружения. Ключа EIA
нет, и без него источник в контур не включается.

Путь именно корневой: `research/sources.py` ищет файл рядом с модулем и **вверх
по дереву до корня репозитория**. Положить его в `research/` тоже сработает, но
канон — корень, как записано в `CLAUDE.md` и `research/README.md`. Проверка одна
и дешёвая: `python smoke.py` из `research/` обязан дать **42/42**; строка «без
ключа: 20» означает, что файл не найден.

## Связь с остальным флотом

Кода здесь нет. Когда инструмент дойдёт до реализации, он ляжет в
`loodo-ai-advisor`, а числа свёртки поедут туда **порождённым машинным
артефактом**, а не переписыванием из этого markdown руками: транскрипция —
тот же класс ошибки, что две разошедшиеся таблицы весов, за который проект уже
заплатил.

История до 2026-08-03 велась внутри `loodo-ai-advisor` в
`docs/knowledge/market-cycle/` и перенесена сюда целиком — 137 коммитов.
